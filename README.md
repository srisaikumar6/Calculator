# Orbit Calculator

A polished, responsive calculator with keyboard support, parentheses, percentages, and safe expression parsing.

## Features

- Keyboard and on-screen controls
- Operator precedence, parentheses, and percentages
- Clear error messages, including division by zero
- Responsive layout with no external dependencies

## Run locally

Open `index.html` in a browser. No build step or external dependencies are required.

## Deployment

GitHub Pages deploys automatically from `main` through the included Actions workflow.
